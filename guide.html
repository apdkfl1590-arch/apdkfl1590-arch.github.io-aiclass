작업자 페이지 사용법

사진을 검사하고 결과를 보고서로 저장하는 순서입니다.

작업자 페이지 열기

  1. 1. 작업 정보를 입력합니다

    화면 위쪽에 작업자 이름, 작업장소, 납기를 적습니다. 작업장소와 납기는 보고서 출력에 꼭 필요합니다. 비워 두면 입력 안내가 나오고 보고서가 저장되지 않습니다.

    예: 작업장소 `A동 1라인`, 납기 `2026-11-22`. 관리자에게 등록된 장소와 연결하려면 같은 장소 이름을 사용하세요. 영문 대문자와 소문자는 구분하지 않습니다.

  2. 2. 용접 방법을 고릅니다

    사진을 올리면 화면이 외관 지표를 바탕으로 용접 방법을 먼저 추천하고 자동 선택합니다. 추천과 다른 방법을 직접 누르면 주의 안내가 표시됩니다. 사진만으로 용접 방법을 확정할 수는 없으므로 실제 작업 기록과 맞는지 확인하세요.

    선택 항목: SMAW(피복 아크), GMAW(MIG/MAG), GTAW(TIG), FCAW(플럭스 코어드), SAW(서브머지드)

  3. 3. 용접 사진을 준비합니다

    `내 용접 사진 직접 올리기`를 눌러 사진을 선택하거나, 웹캠 촬영을 이용합니다. 먼저 사용법을 확인하고 싶으면 아래 샘플 사진을 눌러도 됩니다. 샘플은 연습용이므로 실제 작업 판정으로 사용하지 마세요.

  4. 4. 검사를 시작하고 결과를 확인합니다

    `AI 용접 품질 측정 및 진단 시작`을 누릅니다. 결과 화면에서 품질 점수, 비드 폭, 표면 거칠기, 예상 결함률과 결함 설명을 확인합니다.

  5. 5. 보고서를 출력합니다

    작업자 이름·작업장소·납기가 모두 입력됐는지 확인하고 `리포트 출력`을 누릅니다. PDF에는 검사 결과와 함께 작업장소, 납기, 작업 사진이 들어가며 관리자 페이지의 전송 파일 목록에도 기록됩니다.

확인하고 관리하기

관리자 페이지 사용법

작업자 보고서 확인, 장소별 정보 등록, 검토 우선순위 조정 방법입니다.

관리자 페이지 열기

작업자 전송 파일 확인

`조치 필요`에는 품질 확인이 필요한 파일, `정상`에는 상태가 양호한 파일이 나옵니다. 사진은 목록에서 바로 볼 수 있고, `보고서 열기`를 누르면 작업장소·납기·측정값·결함 설명을 자세히 볼 수 있습니다.

납기가 지난 파일에는 `종료된 작업일 수 있습니다` 안내가 표시됩니다. 보고서의 작업장소와 납기를 먼저 확인하세요.

장소별 작업 정보를 등록하고 반영하기

  1. 작업장소, 현재 작업명, 건당 재작업비, 고객등급을 입력합니다.
  2. `장소 정보 저장`을 누릅니다. 저장한 날짜와 시간이 표시됩니다.
  3. `장소 정보 반영`을 눌러 작업자 파일에 적용합니다.
  4. 작업자 보고서의 장소 이름과 같은 파일에만 작업명·재작업비·고객등급이 들어갑니다. A동과 a동은 같은 장소로 봅니다.

설정 내용을 바꾼 뒤에는 다시 `저장`하고 `반영`을 눌러야 파일에 적용됩니다.

목록 정렬과 중요도 설정

정렬 기준은 납기기일, 결함 치명도, 재작업비용, 고객사 등급 네 가지입니다. 오른쪽 오름차순/내림차순 버튼으로 순서를 바꿉니다.

`중요도 산출 기준 설정`의 톱니바퀴를 누르면 각 기준의 숫자와 AI 위험률을 조정할 수 있습니다. 바꾼 뒤 `식 적용`을 눌러야 계산 결과에 반영됩니다.

장소 정보를 삭제할 때

저장된 장소 옆 `삭제`를 누르면 확인 창이 나옵니다. 삭제할 때는 `예`, 취소할 때는 `아니요`를 누릅니다. 삭제하면 해당 장소에 저장·반영된 정보가 함께 지워집니다.

웹사이트 설명

WELD-AI는 용접 사진을 살펴보고 작업 기록과 보고서를 정리하는 시제품입니다. 사용 방법과 분석 범위를 아래에서 확인하세요.

판별에 사용하는 용접 방법

작업자는 사진을 올리기 전에 실제 작업 방법을 선택합니다. 현재 화면에서 선택할 수 있는 방법은 아래 다섯 가지입니다.

  • SMAW · 피복 아크 용접
  • GMAW · MIG/MAG, 가스 메탈 아크
  • GTAW · TIG, 알곤 용접
  • FCAW · 플럭스 코어드 아크 용접
  • SAW · 서브머지드 아크 용접

화면에서 확인하는 결함 종류

  • 기공 · 용접부 안팎에 작은 구멍이나 빈 공간이 생긴 상태입니다. 구조에 영향을 줄 수 있어 주의가 필요합니다.
  • 스패터 · 용접 중 튄 금속 알갱이가 주변에 붙은 상태입니다. 표면 정리와 작업 조건을 확인합니다.
  • 언더컷 · 용접 비드 가장자리가 파여 움푹해진 상태입니다. 경계 부분을 자세히 확인합니다.
  • 양호 · 시제품 기준으로 큰 이상이 적다고 표시한 상태입니다.

위 목록은 현재 화면의 시연/분석 기준입니다. 사진만으로 모든 내부 결함을 확정할 수 있는 것은 아닙니다.

표면 조도
표면이 얼마나 거친지 참고값으로 표시합니다.
예상 구조적 결함율
사진에서 이상 징후가 얼마나 보이는지 나타내는 시제품 추정값입니다. 실제 불량률을 보증하지 않습니다.
